# 상하차의 신 (God of the Dock)

택배 창고를 운영하며 입고 물량, 보관 공간, 배송 계약, 현금과 평판을 관리하는 모바일 우선 물류 경영 게임입니다. HTML5와 Three.js로 동작하며 Capacitor를 통해 Android 앱으로 패키징할 수 있습니다.

## 최근 업데이트 — 성장과 연쇄 보상

- **실시간 계약(🚨)**: 철도·해상처럼 원래 월말 마켓에서만 살 수 있던 계약을 "투자" 메뉴에서 바로 고용할 수 있습니다. 아직 안 열린 계열(예: 대형 화물 이전)은 마켓과 똑같이 안 보이고, 즉시 고용은 평소 가격의 1.5배입니다 — 급할 때 웃돈을 내고 당겨 쓰는 개념입니다.
- **도크 인부가 실제로 걸어다니며 일합니다**: 트럭이 없을 땐 창고 앞을 오가며 잡일을 하고, 배차가 들어오면 창고↔트럭을 왕복하며 상자를 직접 들어 나릅니다. 트럭에 실린 상자는 더 이상 사라지지 않고 짐칸에 그대로 쌓여, 꽉 찬 트럭과 텅 빈 트럭이 눈으로 구분됩니다. 직접 배송은 트럭 없이 인부가 상자를 들고 마당 밖으로 직접 뛰어나갔다 옵니다. 연쇄·폭주·고가 배송·미션 등급 상승처럼 잘 풀리면 팔을 번쩍 들고 통통 뛰고, 파손이나 평판 페널티처럼 일이 꼬이면 팔이 축 처지고 고개를 숙입니다.
- **월간 미션 등급을 재조정**: A등급 문턱을 크게 올려 진짜 도전 목표로 만들었습니다(자동 플레이 시뮬레이션 기준 달에 한 자릿수%만 A 도달). 진행 막대에는 C·B 경계 눈금이 보이고, 다음 등급이 코앞이면 배지와 막대가 함께 펄스로 재촉합니다. 등급마다 막대 색이 D→C→B→A로 바뀝니다.
- **여러 대 호출은 실제 여러 대가 동시에 옴**: 2대 이상을 호출하면 그만큼의 트럭이 도로에 나란히 서서 한꺼번에 도크로 들어와 각자 자기 몫의 상자를 싣고 동시에 출차합니다. 적재 화면에서 나눈 차량별 화물이 3D 출고 연출에도 그대로 이어지며, 트럭이 들어올 때마다 엔진음이 겹쳐 재생됩니다.
- **그림으로 적재하는 호출 화면**: 차량 호출 창에 실제 적재 칸 격자를 추가했습니다. 택배를 누를 때마다 같은 색 상자가 트럭 안에 쌓이고, 여러 대를 쓰면 트럭도 늘어납니다. 수익·배차 비용·순수익은 큰 숫자 카드로 동시에 변합니다.
- **누를 수 있는 3D 현장**: 3D 상자를 누르면 개별 배송 정보, 창고·마당·저온 구역을 누르면 용량과 위험, 차량을 누르면 계약별 적재량과 남은 배차가 열립니다. 투자 시설을 누르면 사업 확장 메뉴로 바로 이동합니다.
- **접힌 화면 보강**: 새 게임은 재고 정보가 접힌 상태로 시작합니다. 접어도 색상별 상자 수와 사용 칸을 작은 재고 스트립으로 계속 보여 주며, 칩을 누르면 전체 목록이 펼쳐집니다. 카메라는 접힌 화면에서 전체 창고와 차량이 들어오도록 더 멀리 잡습니다.
- **접을 수 있는 창고 정보**: `입고 예정 + 재고 묶음 행`을 하나의 서랍으로 구성했습니다. 창고 게이지의 `재고 접기/펼치기` 버튼으로 숨길 수 있고, 접으면 3D 창고가 더 넓어집니다. 선택한 상태는 다음 실행에도 유지됩니다.
- **화면 밀도 재조정**: 기본 창고 3D 영역을 화면의 약 44%로 줄여 택배와 조작 영역을 더 넓혔습니다. 메인 택배 목록과 입고 예정에서는 `일반` 같은 반복 종류명을 제거하고 색상 칩·속성 아이콘·크기·금액만 보여 줍니다. 정확한 종류명은 색상 칩의 툴팁과 상세 화면에서 확인할 수 있습니다.
- **퍼펙트 로드 연쇄**: 트럭을 80% 이상 채운 출고를 이어 가면 2연쇄부터 수익이 1.08배, 1.16배, 최대 1.24배까지 상승합니다. 대기하거나 적재율이 낮은 트럭을 보내면 연쇄가 끊깁니다.
- **월간 미션 등급**: 매달 수익 목표가 D·C·B·A 등급으로 표시됩니다. C, B, A급에 도달할 때마다 즉시 성장 보너스를 받으며 현재 금액과 다음 등급까지 남은 금액을 HUD에서 계속 확인할 수 있습니다.
- **화물 가치 외형**: 보상이 높은 상자는 청색 띠, 금색 이중 포장, 자주빛 발광 포장으로 단계적으로 화려해집니다. 화물 목록에도 같은 가치 배지가 표시됩니다.
- **확장된 투자 트리**: 홍보·차량·창고에 자동화·브랜드·저온 물류를 추가했습니다. 차량 Lv.2가 자동화를, 홍보 Lv.2와 자동화 Lv.1이 브랜드를, 창고 Lv.2가 저온 물류를 해금합니다.
- **눈에 보이는 성장**: 투자 단계에 따라 창고 지붕 설비, 광고판, 컨베이어, 브랜드 조형물, 냉각 탱크, 트럭 조명과 장식이 3D 현장에 실제로 추가됩니다.
- **강화된 피드백**: 연쇄 시작부터 최대 연쇄, 고가 화물 출고, 미션 승급, 투자 완료까지 단계별 음향·파티클·화면 강조가 발생합니다.
- **튜토리얼 개편**: 첫 안내에서 퍼펙트 로드와 미션 등급을 설명하며, 첫 출고 이후 실제 HUD를 가리켜 연쇄와 등급 보상을 다시 안내합니다.
- **모바일 가독성 개선**: 기본 글자와 핵심 숫자, 택배 행, 계약 카드, 주요 버튼을 키우고 투자 화면은 현재 효과와 다음 해금 중심으로 간결하게 정리했습니다.
- **업데이트 즉시 반영**: 핵심 JS·CSS·번역 파일에 버전 값을 붙여 새 HUD와 그래픽이 브라우저 캐시에 가려지지 않도록 했습니다.

## 게임의 핵심

- 매 영업일 들어오는 택배를 창고와 냉장·냉동 구역에 배치합니다.
- 배송 업체를 골라 차량을 호출하고 적재 효율과 배송 기한을 관리합니다.
- 과적, 반송, 파손, 날씨, 도난 위험을 피하면서 현금과 평판을 성장시킵니다.
- 캠페인을 진행하며 새 기능, 고객, 배송 수단과 운영 선택지를 해금합니다.

수익은 운영 중 언제든 여섯 가지 성장 축에 다시 투자할 수 있습니다.

- **홍보**: 다음 영업일부터 들어오는 택배가 늘어납니다.
- **트럭**: 보유한 모든 배송 계약의 배차 횟수가 늘어나며 이후 계약에도 적용됩니다.
- **창고**: 보관 공간이 즉시 확장되고 3D 창고 규모에도 반영됩니다.
- **자동화**: 배차비와 초과 물량 인건비를 줄이고 창고 안에 컨베이어 설비를 설치합니다.
- **브랜드**: 모든 화물의 기본 가치를 높이고 프리미엄 화물이 들어올 확률을 올립니다.
- **저온 물류**: 냉장·냉동 공간을 함께 늘리고 전용 냉각 설비를 설치합니다.

처음에는 한 사이클에 약 9개의 택배만 들어옵니다. 홍보 레벨을 올릴 때마다 사이클 기준 물량이 3개씩 늘어나므로, 운송력과 창고를 함께 키우지 않으면 병목이 생깁니다.

창고 사용률이 72%를 넘으면 **도크 러시**가 준비됩니다. 이때 임시 트럭 2대가 추가되고, 여러 대를 72% 이상 채워 재고의 55% 이상을 한 번에 출고하면 배송 수익이 35% 늘고 평판도 오릅니다. 더 쌓으면 보상이 커지지만 95%부터는 다음 입고 한 번에 야적·도난·반송 위험이 연쇄적으로 터질 수 있습니다.

이 루프는 대표적인 모바일 경영 게임의 ‘생산–운송–보관 병목을 투자로 해소하는 성장’과 ‘트럭 주문 이벤트의 큰 보상’을 택배 창고 운영에 맞게 결합한 것입니다. 화면의 러시 게이지, 호출창 예상 보상, 실제 정산은 모두 같은 규칙을 사용합니다.

화면은 3D 창고를 중심으로 구성됩니다. 모바일 화면의 절반 이상을 실제 상자 적재와 차량 이동에 할당하고, 운영 상태는 접는 카드 대신 항상 보이는 한 줄 신호와 진행 바로 요약합니다. 하단은 `트럭 선택 → 오늘 마감` 순서의 고정 조작부이며, 매일 쓰는 `투자`만 함께 둡니다. 고객·기록·도움말은 설정 화면의 2차 기능으로 정리했습니다.

레이아웃은 [Idle Miner Tycoon](https://play.google.com/store/apps/details?id=com.fluffyfairygames.idleminertycoon)의 큰 작업 현장과 문맥형 성장 조작, [MONOPOLY GO!](https://play.google.com/store/apps/details?id=com.scopely.monopolygo)의 한 화면 한 주 행동 구조를 참고했습니다. 그대로 복제하지 않고 `창고를 본다 → 트럭을 고른다 → 오늘 마감한다`는 이 게임의 판단 순서에 맞게 재구성했습니다.

턴을 넘기는 행동은 ‘대기’가 아니라 **오늘 마감**으로 표시합니다. 플레이어가 할 일을 끝냈다는 확신을 주고, 버튼과 확인 화면에서 마감 직후 받게 될 다음 입고와 예상 창고 사용량을 먼저 보여 줍니다. 직접 배송과 적재 정리는 마감 전에 처리하는 추가 업무입니다.

## 로컬 실행

요구 사항: Node.js 18 이상, Python 3

```bash
npm install
npm run serve
```

브라우저에서 `http://localhost:8765`를 엽니다. 게임 데이터는 브라우저의 `localStorage`에 자동 저장됩니다.

## 테스트

```bash
npm test
```

`npm test`는 게임 규칙 단위 테스트와 200회 자동 시뮬레이션을 실행합니다.

모바일 레이아웃은 390×800과 360×640을 기준으로 화면 밖 스크롤, 조작 요소 겹침, 3D 현장과 하단 조작부의 비율을 확인합니다.

## 웹 빌드

```bash
npm run web
```

웹 배포용 산출물과 아카이브를 생성합니다.

## Android APK

요구 사항: Android Studio, Android SDK, JDK

```bash
bash build-apk.sh
```

처음 직접 구성할 때는 다음 순서로 Capacitor 프로젝트를 준비할 수 있습니다.

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

## 프로젝트 구조

| 경로 | 역할 |
|---|---|
| `www/index.html` | 게임 화면 구조와 HUD |
| `www/css/style.css` | 반응형 레이아웃, 픽셀 UI, 운영 상태 시각화 |
| `www/js/game.js` | 핵심 규칙과 게임 상태 머신 |
| `www/js/ui.js` | 화면 렌더링, 입력, 모달, 피드백 |

| `docs/` | 게임 및 시스템 설계 문서 |

## UI 원칙

1. 실제 창고 상태가 가장 큰 화면을 차지한다.
2. 위험은 빨강, 주의는 노랑, 안정은 초록으로 즉시 구분한다.
3. 매 턴 성과와 성장 진행률을 숫자와 게이지로 보여 준다.
4. 번 돈은 정산을 기다리지 않고 홍보·차량·창고·자동화·브랜드·저온 물류에 즉시 재투자할 수 있다.
5. 물량을 쌓는 긴장과 한 번에 출고하는 보상 폭발을 게이지·소리·화면 효과로 즉시 전달한다.
6. 상세 설명은 필요할 때만 열고, 기본 화면의 텍스트 밀도를 낮춘다.
7. 모바일에서도 주요 조작이 한두 번의 탭 안에 있어야 한다.
8. 한 화면에는 하나의 주 행동만 강하게 보여 주고, 보조 정보와 저빈도 기능은 탭해서 펼친다.

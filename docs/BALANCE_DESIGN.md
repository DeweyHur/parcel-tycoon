# 택배 타이쿤 — 차량·신뢰도·긴장감 재설계 기획서 v0.3

플레이테스트(v0.9) 결론: 너무 쉽다. 이 문서는 게임의 성격을 한 문장으로 못 박고, 그 성격이 나오도록 축을 다시 정한다. (기획 본문은 claude.ai 프로젝트 `claude/BALANCE_DESIGN.md`와 같다. 아래 "구현값"이 실제 코드 값이다.)

> **이 게임은**: 계약은 마켓에서만 살 수 있고, 매 호출이 돈이며, 자금이 마르지 않게 대기와 호출을 타이트하게 운영하는 게임이다. 초반은 일반 택배만 궁하게 돌리고, 고객 신뢰가 쌓이면 특수 물품이 열리며, 계약·신뢰도를 **특화**해 스노우볼을 굴려야 후반에 쏟아지는 택배를 감당한다.

## 1. 차량 모델
계약 = 차량(용량 N칸) + 대당 배차비(호출 즉시 차감) + 월 배차 한도(매월 리셋, 계약은 만료되지 않음) + 동시 대수(기본 1, 신뢰 특성·동시 배차 강화로 +1). 부피 합이 용량을 넘으면 차 한 대 더. 80% 이상 채우면 신뢰 xp +1.
조커 업체(용달·긴급 특송) 삭제. 유연성은 직접 배송(대기 턴 1개, 배송비 15+5×크기) + 차량 시설(냉동 탑차·완충 포장차·대형 트럭·배송 기사).

## 2. 신뢰도 특성 (업체별 1/2/3단계)
대량 동시 2대 / 배차비 -30% / 일반 +5 · 냉장 용량 +2 / 호출 턴 기한 정지 / 냉장 구역 +2 · 냉동 배차비 -20% / 용량 +2 / 냉동 구역 +2 · 프래자일 배차비 -20% / 동시 2대 / ⚠ +15 · 통관 대기 -1 / 용량 +4 / 지연 무효 · 대형 초대형 점유 -1 / 동시 2대 / 대형 +10 · 항공 크기 4 / 배차비 -30% / 통관 중 +20 · 철도 지연 없음 / 한도 +1 / 용량 +6 · 해상 지연 1 / 용량 +6 / 지연 없음.

## 3. 고객 품목 해금
0단계 일반 85% · 1단계 55% · 2단계 고객 정의 · 3단계 + 프리미엄 품목 25%(보상 ×1.5). 일반은 물량, 특수는 단가.

## 4. 등급(프리미엄 계약)
표준 / 프리미엄(용량 +2, 한도 +1, 배차비 -15%, 신뢰 3xp, ×2.2) / 엘리트(+4, +2, -30%, 8xp, ×4) / 마스터(+6, +3, -40%, 15xp, ×7). 마켓: 보유 업체는 더 높은 등급일 때만 등장(업그레이드).

## 5. 구현값 (v1.0, 봇 시뮬로 조정)
| 항목 | 기획 | 구현 |
|---|---:|---:|
| 시작 자금 / 운영비 | 450 / 150 | 450 / **300** |
| 배차비 (대량·냉장·냉동·프래·통관·대형·항공·철도·해상) | 30·40·45·40·60·55·70·80·70 | **70·95·110·95·140·135·165·190·165** |

| 기한 | 일반 4·파손 5·통관 5·대형 6·냉동 5·농산 4 | 그대로 |
| 입고 | 월 15 +2/월 | **월 22 +2/월** (EXTRA_ARRIVALS 12/14/16/18/20/22) — 15는 트럭이 안 차서 심심하다는 피드백 |

이유: 기획값(운영비 150, 배차비 30~80)으로는 봇이 99% 생존 — 수입이 배차비의 5배라 자금 압박이 없었다. 입고를 월 22로 올리자(트럭이 2턴이면 찬다) 수입이 더 늘어, 운영비 300·배차비 ×2.3·일반 단가 -20%로 표준 72%, 월말 평균 자금 500대. 원칙: **입고를 늘리면 반드시 운영비·배차비도 같이 올려야** 자금이 마른다. 고객 0단계는 일반만, 1단계 30% 특수, 익명 1개월차 일반 85%(신선 0). 회사 시작 자금은 동네 450 / 프레시 380 / 강철 350 / 도심퀵 420 / 글로벌 380 / 유리방 420 / 짠돌이 560 / 스타트업 260 / 국영 450(운영비 230·배차비 70 고정).

# 상하차의 신 — 출시·BM 계획 v0.2

결정(2026-09-13): **웹 데모 먼저 공개**, BM은 **무료 데모 + 1회 언락**.
결정(2026-09-25): **무료 = 봄(인수인계) + 여름. 가을부터 본편.** 여름을 넘기면 결과 화면이 상점 안내로 보낸다. (아래 2절이 v0.1의 "인수인계 3개월 컷"을 대체)

## 1. 3단 배포 구조

| 단계 | 채널 | 형태 | 목적 |
|---|---|---|---|
| 1 | itch.io + 웹 아티팩트 | 무료 데모(결제 없음) | 플레이테스트 피드백, 초기 관심·위시리스트 |
| 2 | Google Play | 무료 설치 + 1회 언락 IAP | 모바일 본편 |
| 3 | Steam (+ STOVE 인디) | 데모 + 유료 본편 | PC 관객. 턴제·수치 관리라 본 무대 |

선택 사항: 원스토어·갤럭시 스토어는 Play용 APK 그대로 올리면 되니 나중에 추가. App Store는 Capacitor iOS 타깃 + $99/년이라 2단계 반응을 보고 결정.

**웹에는 결제를 붙이지 않는다.** 웹 결제는 전환율이 낮고 심사·환불 처리가 전부 직접 일이 된다. 웹 데모의 역할은 "본편은 Play/Steam에서" 로 보내는 것.

## 2. 데모 경계 (2026-09-25 개정)

첫 해는 한 창고의 이야기로 이어진다 (STORY_TUTORIAL_DESIGN 부록 BB).

| 런 | 무엇 | 시작 판 | 무료판 |
|---|---|---|---|
| 🌸 봄 (3~5월) | 인수인계(캠페인) 서장~5장. 처음엔 이것만 할 수 있다(타이틀이 캠페인 전용) | 대본 | ✅ |
| ☔ 여름 (6~8월) | 박 반장 없이 혼자. 캠페인 보정·noBankrupt 없음 | 5장을 끝낸 창고 | ✅ |
| 🎑 가을 (9~11월) | 추석 폭주·연휴 | 여름을 넘긴 창고 | 🔒 본편 |
| ❄ 겨울 (12~2월) | 연말·설 | 가을을 넘긴 창고 | 🔒 본편 |
| 반기·한 해 | 겨울을 넘기면 열린다 (다른 나라 달력도 여기로) | 기본 창고 | 🔒 본편 |

- 계절 런은 **몇 번이든** 다시 할 수 있고, 매번 같은 시작 판에서 출발한다. 앞 계절을 다시 넘기면 그 판으로 바뀐다.
- 무료판 이유: 사기 전에 보정 없는 "진짜 판"(빠듯한 현금·부도)을 여름 한 번은 혼자 겪어 봐야 한다. 컷은 "9월, 추석이 온다" 직전 — 결제하면 같은 창고로 가을이 이어진다.
- 여름에서 망하면 여름을 다시 한다(무료). 본편 안내는 여름을 **넘긴** 결과 화면에서만.
- 무료판 런 선택 화면에는 가을·겨울을 🔒「본편에서」로 보여 준다. 누르면 본편 안내.

## 2.1 구현 상태 (2026-09-25, `feat/season-chain`)

- `META.FREE_RUNS = ['kr_spring', 'kr_summer']`, 런 정의에 `campaign` · `chainFrom` · `chainNext`
- `Profile.chainStart(id)` — 여름은 `campaign.carryAt[7]`(5장 끝 판), 가을·겨울은 `profile.chain[id]`(앞 계절 완주 때 `recordRun` 이 저장)
- 겨울 완주(`kr_winter_clear`) → 상·하반기·한 해. 옛 `kr_spring_clear`·`kr_seasons`·`kr_half` 삭제
- `BUILD.demoMonths` · `_finishDemo` 삭제. `tools/build-web.py --demo` 는 그대로 `demo: true` 한 줄만 바꾼다
- 프로필 내보내기 코드에 `campaign`·`chain` 포함 — 데모에서 넘긴 여름이 Steam 본편에서 가을로 이어진다
- 테스트: 단위 100 · `runs-ui` 31(본편 사슬 + 무료판 경계) · `play-ui` · `level-ui` · `intro-ui` · `campaign-run`

남은 것: `BUILD.store` 링크 채우기, 모바일 IAP 플러그인 연결(`BUILD.iap`), itch.io 페이지 개설.

## 3. 언락 구현

설계 원칙 2(해금은 도전과제로)와 충돌하지 않게, 돈으로 사는 것은 **본편 접근권 하나**뿐이다. 회사·시나리오·퍽 슬롯은 계속 도전과제로만 열린다.

- `profile`에 한 겹 추가: `license = { full: bool, source: 'demo'|'play'|'steam'|'ios' }`
- 빌드 플래그 `BUILD.demo`: 런 선택 화면에서 `FREE_RUNS` 밖(가을·겨울·반기·한 해)을 잠근다
- 세이브 이어받기: 모바일은 같은 앱이므로 IAP 직후 그대로 이어진다. Steam은 별개 설치라 **프로필 내보내기/가져오기**(JSON → base64 코드 문자열)를 하나 붙인다 — `profile` 구조가 이미 직렬화 가능하니 화면 하나면 된다.
- 데모 세이브는 본편 스키마와 동일하게 유지(버전 필드만 확인)

## 7. 하지 않기로 한 것

- **보상형·전면 광고**: 런 중 이득을 주는 보상형은 도전과제 해금과 데일리 시드 기록을 무의미하게 만든다. 월말 정산마다 전면 광고는 정산→마켓→다음 달 계획의 호흡을 끊는다. eCPM도 한국 기준 기대치가 낮다.
- **해금 판매**: 회사·시나리오·퍽 슬롯·마켓 새로고침·파산 후 이어하기 전부 제외.
- **캐주얼 웹 포털(CrazyGames·Poki)**: 광고 수익 배분은 60%/50%로 나쁘지 않지만 한 런 30~120턴은 포털의 3분 세션 패턴과 맞지 않는다. 데모 유통 채널로만 고려.

### 바꾼 것 / 안 바꾼 것

바꾼 것은 **플레이어에게 보이는 이름뿐**이다 — `title.name`·`title.sub`, `index.html` 의 `<title>`, Capacitor `appName`, Android `app_name`, `tools/build-web.py` 의 문서 제목, README·기획서 헤더.

건드리지 않은 것: 레포 이름 `parcel-tycoon`, git remote, Vercel URL, `appId com.dewey.parceltycoon`, 빌드 산출물 `parcel-tycoon.html`, 그리고 **`localStorage` 접두사 `pt_`**. 마지막 것이 제일 중요하다 — 프로필·세이브·언어가 전부 이 접두사라서 바꾸면 지금까지의 플레이테스트 프로필이 전부 날아간다.

### `title.goal` 을 지웠다

「3월에 인수해서 분기·반기·한 해」는 **서장에서 전부 틀린 말이다.** 서장은 4사이클 고정이고 평판은 꺼져 있다(부록 R·U). 캠페인을 처음 켠 사람이 보는 첫 문장이 그 사람에게 해당 없는 규칙이면 안 된다. 승리 조건은 이미 「게임 방법」 카드 · `story.intro.1` · 박 반장 첫날 대사 세 군데서 말한다.

`title.modal`(「택배 회사 게임」)도 지웠다. 제목이 생겼으니 그 위의 머리띠는 같은 말을 두 번 하는 것이다 — `modal()` 이 제목 없이 불리면 `<h2>` 를 아예 그리지 않는다.

### 1장 스튜디오 → 2장 타이틀

`www/js/splash.js`. **2장은 별도 화면이 아니라 기존 `showTitle()` 그 자체다** — 스플래시를 띄우고 나서 타이틀을 또 그리면 「상하차의 신 / 택배 창고 타이쿤」 두 줄을 2초 안에 두 번 말하게 된다.

- 아치 로고가 한 칸 위에서 내려앉고(steps), 문 안쪽 하늘을 별 하나가 꼬리를 끌며 가로지른다. 아치 안쪽 하늘 모양 `clipPath` 로 잘라서 석재 틀 뒤로 사라진다
- 모든 동작은 `steps()` — 도트가 미끄러지지 않고 칸 단위로 튄다
- 아무 데나 누르면 즉시 2장. `prefers-reduced-motion` 이면 애니메이션 생략
- **2회차부터 1.9초 → 0.45초.** `localStorage` 가 아니라 `Profile.splashSeen` 에 붙였다 — 재실행이 잦은 로그라이크다
- 도트는 `'fill|x,y,w,h ...'` 로 인코딩해 한 파일에 박았다. `<rect>` 태그로 쓰면 34KB, 이러면 7KB. 외부 요청이 없어야 `tools/build-web.py` 의 단일 파일 빌드에 그대로 실린다
- `?nosplash` 로 끌 수 있다 (테스트용)

### 메인 메뉴를 단순하게

타이틀 화면은 이제 모달 틀을 벗는다(`.modal.titlecard` + `#modal-root.title-mode`). 제목이 곧 머리다.

```
상하차의 신
택배 창고 타이쿤
   [ 시작하기 ]          ← 버튼 하나. 도트 톤 4px 오프셋 그림자
     서장                 ← 세이브가 있으면 「서장 · 처음부터」
효과음: 켜짐  음악: 켜짐  언어: 한국어     ← 버튼 세 개가 아니라 텍스트 한 줄
DOO'IN STUDIO · v0.3
```

세이브가 있으면 CTA 가 「이어하기」가 되고 「처음부터」는 작은 링크로 내려간다. 소리·음악·언어는 **아이콘으로 바꾸지 않았다** — 도트 화면에 아이콘을 넣으면 에셋을 또 정수배로 관리해야 하고, 세 글자가 더 짧게 끝난다.

`:has()` 대신 클래스 토글을 쓴다(구형 웹뷰). `modal()` 이 불릴 때마다 두 클래스를 먼저 떼므로 다음 모달로 딸려가지 않는다.

### 에셋

`www/img/` — `mark-grand.svg/.png`(아치 64px), `mark-grand-128.png`, `mark-grand-nofig.svg`(텍스트 겹치는 배너용), `logo-grand-dark/-light.svg`(세로 조합), `mark-only.svg`(**게임 아이콘** — 스튜디오 마크가 아니다), `mark-icon.png`(36×36 파비콘). SVG 는 픽셀 한 줄이 `<rect>` 하나라 어떤 크기로 키워도 뭉개지지 않는다. 파비콘은 `index.html` 과 단일 파일 빌드 양쪽에 붙였다.

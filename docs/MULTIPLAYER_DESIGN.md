# 상하차의 신 — 멀티플레이 「난투」 설계 (v0.1)

## 0. 한 줄

**4인이 각자 시계로 석 달을 굴린다. 끝까지 살아남고, 살아남은 사람끼리는 잔액으로 겨룬다.**
개인 런이 "차분히 쌓는 판"이라면 멀티는 "펑펑 터지는 판"이다. 규칙은 개인 런에서 **빼고**(새 계약·배차 제한·어음·명절), 연출과 상호작용을 **더한다**(트레잇·폭탄·퍽 3택1).

이 문서의 모든 규칙은 **멀티 전용**이다. 개인 런·캠페인은 건드리지 않는다.

## 1. 경기 규칙

| 항목 | 값 |
|---|---|
| 인원 | 2~4인 (4인 목표, 매칭 대기 후 미달이면 봇으로 채움 — §9) |
| 길이 | 석 달 = 6사이클(반월) = 약 72영업일. 명절·연휴 없음(달력은 시각만) |
| 시간 | **공유하지 않는다.** 각자 자기 날짜를 진행한다 (§2) |
| 종료 | 평판 0 → **폐업**(기존 규칙 그대로). 잔액이 마이너스면 호출을 못 해 물량이 쌓이고 결국 평판으로 죽는다 — 죽는 이유는 개인 런과 같이 하나다 |
| 승부 | ① 생존자 > 폐업자 ② 생존자끼리 **최종 잔액** ③ 동률이면 평판 ④ 폐업자끼리는 늦게 죽은 순 |
| 입고 시드 | **매치 공유** — 넷이 같은 입고 대본을 받는다. 운은 트레잇 발동과 폭탄 목적지에만 있다 |
| 물량 | 일차에 비례해 오른다: `arrivals × (1 + 0.025 × day)`, 마지막 보름은 ×1.5 「마감 폭주」 |

## 2. 시간 — 눌러야 간다, 마켓도 하루다

타이머 없음. 개인 런처럼 호출·대기를 눌러야 다음 날이다. 넷의 시계는 각자 돈다.

- **마켓에 들어가는 것이 하루를 쓴다.** 마켓 = 「장 보러 간 날」: 입고는 쌓이고 배송은 없다. 그래서 자주 못 들어가고, 들어가면 한 번에 사고 나와야 한다(§6). "마켓에서도 시간이 간다"는 이 한 줄로 구현된다.
- 퍽 3택1·창고 팝업·상대 포트레잇 탭은 시간을 쓰지 않는다.
- 주말 카드 없음. 일요일은 그냥 지나간다(입고만 쌓임).
- 상대에게서 온 공격은 **받는 사람이 다음 날로 넘길 때** 적용된다(큐). 빠른 사람은 일찍 쏘고, 느린 사람은 초반 날짜에 그걸 다 맞는다 — 서두를 이유가 여기서 난다.
- **먼저 끝낸 사람** = 「마감」. 잔액 확정, 이후 날아오는 공격·폭탄은 무효(닫은 창고엔 못 넣는다), 남은 사람들을 관전. 마감한 뒤 큐에 남아 있던 내 공격은 그대로 나간다.
- 마지막 30일부터 HUD에 **D-카운트**.

## 3. 택배 트레잇 — 출고하면 터진다

멀티에서는 입고 택배의 일부(초반 15% → 후반 35%)에 트레잇이 붙는다. **기한 안에 출고하면 발동**, 반송·폐기되면 불발. 아이콘 하나로 읽혀야 한다(개인 런의 품목 아이콘 옆 작은 뱃지).

### 공격 (**나 빼고 전원에게** — 살아있고 마감 안 한 상대 모두)

| 아이콘 | 이름 | 상대에게 |
|---|---|---|
| 🧨 | 이삿짐 폭탄 | §4 |
| 🌧 | 소나기 | 다음 날 야외 적재 전부 「젖음」(기한 −1) |
| 📞 | 클레임 | 평판 −1 |
| 🐭 | 쥐 | 신선 품목 1개 즉시 폐기 |
| ⏱ | 독촉 | 창고 안 모든 택배 기한 −1 |
| 🚧 | 도로 통제 | 다음 날 호출 불가 |
| 💸 | 반품 | 반송 1건 강제(평판 −1 상당) |
| 🔒 | 창고 봉인 | 창고 상한 −3칸, 3일 |

### 보너스 (나에게)

| 아이콘 | 이름 | 효과 |
|---|---|---|
| 💰 | 웃돈 | 이 택배 보수 ×2 |
| ⭐ | 입소문 | 평판 +1 |
| 🛡 | 방패 | 다음 공격 1회 무효 (최대 2겹) |
| 🧊 | 얼음 | 신선 부패 정지 3일 |
| 📦 | 압축 | 창고 +3칸, 3일 |
| 🚚 | 덤 트럭 | 다음 호출 트럭 +1 무료 |
| 🔄 | 되돌리기 | 들고 있는 폭탄 1개를 보낸 사람에게 반송 |
| 🎯 | 한 방 | 다음 공격 트레잇을 **1위 한 명에게만** 보내되 효과 ×3 |

원칙: 전원에게 가는 대신 **한 방은 반나절 손해**를 넘지 않는다(개인 런 사고 하나의 절반). 죽이는 건 공격이 아니라 물량이어야 한다. 공격 트레잇은 등장 비율을 보너스보다 낮게(공격 40 : 보너스 60) 잡아 판 전체가 난타가 되지 않게 하고, 방패·되돌리기·한 방이 있으므로 "맞기만 하는" 판은 안 나온다.

## 4. 이삿짐 폭탄

개인 런의 이삿짐 보관 계약(공간만 쓰는 계약)을 멀티에서는 **폭탄**으로 뒤집는다.

- 트레잇과 달리 **랜덤 상대 한 명**에게만 간다(전원에게 가면 창고가 동시에 터진다).
- **강제 수락.** 마켓 계약이 아니라 입고로 들어온다. 거절 불가, 출고 불가.
- 크기 3칸, 보관료 소액(하루 +2c)이 들어온다 — 그래서 완전히 손해는 아니지만 자리를 먹는다.
- **카운트다운 6일.** 0이 되면 「이사 완료」 — 내 창고에서 사라지고 **랜덤 상대 창고로 날아간다.** 옮겨갈 때마다 **+1칸, 카운트 −1일**(3칸/6일 → 4칸/5일 → 5칸/4일 …). 돌수록 무거워진다.
- 소멸 조건: ① 6칸/1일까지 커진 폭탄은 다음 이사 때 **터진다** — 받은 사람 창고 초과분 도난 판정 1회, 그 뒤 소멸 ② 들고 있던 사람이 폐업하면 같이 소멸 ③ 마감한 사람에겐 못 간다.
- 매치당 동시 폭탄 **최대 4개**(인원 수). 발생원은 🧨 트레잇 출고와 매 사이클 정산 1개 자동 투하.
- 연출: 트럭이 내 창고에서 상대 포트레잇으로 날아가 **쿵** 하고 박힌다. 받는 쪽 화면은 흔들리고 3D 마당에 이삿짐 더미가 실제로 놓인다.

## 5. 평판 → 퍽 3택1

개인 런의 평판 등급(무명·동네 소문·구내 유명·시내 최고)은 멀티에 없다. 평판 게이지는 그대로(0이면 폐업), **등급 문턱을 넘을 때마다** 퍽 카드 3장이 뜨고 1장을 고른다.

- 문턱: 상한 도달 → 상한 +5·등급 +1(개인 런과 같은 사다리). 석 달이면 4~6번.
- 카드는 3계열에서 하나씩 뽑는다. **장착 상한 없음**, 같은 퍽 중복 가능(중첩 수치 표기).
- 팝업은 시간을 쓰지 않는다. 느긋하게 고른다.
- 런 시작 퍽(개인 런의 회사·퍽 선택)은 **없다.** 멀티는 전원 같은 창고·같은 계약으로 시작한다.

| 계열 | 예시 |
|---|---|
| 🛡 방어 | 상시 방패 1겹 · 폭탄 카운트 +2일 · 받는 공격 50% 확률 불발 · 소나기 면역(지붕) |
| ⚔ 공격 | 공격 트레잇 등장 +10%p · 폭탄 옮길 때 +2칸 · 내 공격 효과 ×1.5 · 내 폭탄 이사 시 상대 평판 −1 |
| 💰 경제 | 연속 만차 보너스 ×1.5 · 트럭 1대 무료/일 · 보관료 ×3 · 마감 폭주 보수 +20% · 업그레이드 −20% |

값은 개인 런 퍽 상한(월 40~80c)을 **의도적으로 넘긴다.** 석 달짜리 난투에서 퍽은 양념이 아니라 빌드다.

## 6. 마켓 — 한 화면, 새 계약 없음

들어가면 하루가 가므로(§2) **한 번에 사고 나오는** 화면이어야 한다.

- 언제든 들어갈 수 있다(정산 뒤가 아니라 HUD 버튼, 「장 보기 · 하루」 라벨). 정산은 자동, 팝업 없이 로그 한 줄.
- 내용은 **보유 계약 카드 3장 + 창고 카드 1장**뿐. 매물 없음, 새로고침 없음.
- 계약 카드: 이름·트럭 아이콘 · [▲ 업그레이드 비용] 한 버튼 · 강화 칸 아이콘 줄(냉장·대형·파손 등, 각각 한 버튼). **배차 항목 없음**(배차 제한이 없으므로 리필·한도 업그레이드 삭제).
- 창고 카드: [+칸 비용] · [냉장 +칸] · [마당 +칸].
- 결제는 **즉시 차감**(어음 없음 — 잔액이 곧 점수이므로 눈에 보이는 숫자가 실제 숫자여야 한다). 돈이 모자라면 버튼 회색, 이유 한 줄.
- 시작 계약은 넷 모두 같은 3개(일반·대량·냉장). 차이는 무엇을 먼저 키우느냐에서 난다.

배차 무제한 = 호출은 **배차비만** 든다. 트럭 수 상한도 없다. 대신 배차비가 일차에 따라 조금씩 오른다(유가).

## 7. HUD — 상대가 보인다

상단 한 줄에 **포트레잇 4개**(맨 왼쪽 나). 각 포트레잇 아래:

- 창고 적재 막대(초록→노랑→빨강, 초과는 깜빡임)
- 평판 점 5개
- 잔액 (작게, 순위 색: 1위 금테)
- 진행 일차 (`D+41`) — 시계가 다르니 이게 있어야 "저 사람은 벌써 끝나간다"가 읽힌다

표정은 상태를 따라간다: 기본 / 창고 80%↑ 진땀 / 공격 맞음 놀람 / 1위 웃음 / **폐업 = 그레이아웃 + 망연자실**(표정 프레임 하나 추가). 마감한 사람은 세피아 + 「마감」 도장.
포트레잇을 탭하면 그 사람 창고 요약(계약 3줄·들고 있는 폭탄·퍽 아이콘) — 관전 정보이지 조작 아님.

## 8. 연출 — 여기가 본체

개인 런 것을 다 쓰고 더 얹는다. 전부 화면 중앙 팝 + SFX, 겹치면 큐.

| 트리거 | 연출 |
|---|---|
| 연속 만차 (80%↑ 연속) | 기존 그대로 + 5연속부터 배수 라벨 커짐(×1.2 → ×1.5 → ×2) |
| 점보 / 일괄 출고 | 기존 그대로 + 트럭 대수만큼 포트레잇 밑 잔액이 굴러 올라감 |
| 공격 발사 | 내 창고 → 상대 포트레잇으로 아이콘 궤적, 명중 시 상대 포트레잇 흔들림 + 표정 |
| 피격 | 화면 가장자리 빨간 비네트 0.3초 + 무엇을 당했는지 한 줄 |
| 방패 발동 | 포트레잇 앞에 방패 깨지는 프레임 |
| 폭탄 도착·이사 | §4 |
| 퍽 획득 | 카드 3장 슬라이드, 고르면 나머지 재가 됨 |
| 평판 등급업 | 팡파레 + 게이지 늘어남 |
| 순위 변동 | 「2위로 올라섰다」 토스트, 1위 탈환은 금색 |
| 폐업 (누구든) | 전원 화면에 「○○ 폐업」 배너 + 포트레잇 그레이아웃 |
| 마감 | 「○○ 마감 · 잔액 12,400c」 배너 |
| D-30 / D-7 / D-1 | 카운트 배너, 마지막 날은 BGM 템포 업 |

효과 밀도 목표: **하루에 최소 하나는 뭔가 터진다.**

## 9. 등급 · ELO · 매칭

- 등급(택배 테마): 견습 기사 → 정규 기사 → 조장 → 팀장 → 지점장 → 본부장 → **상하차의 신**. ELO 구간 200씩, 시작 1200.
- 4인 ELO: 순위표에서 **모든 쌍**을 1:1 결과로 계산해 합산(4인 = 3경기 분). K = 32, 30판 후 16.
- 매칭: 같은 등급 ±1 → 30초 후 ±2 → 60초 후 봇 채움(봇은 ELO 변동 반영 안 함, 등급 상위에서는 봇 없음).
- 2인 매치 허용(친구 초대 코드). 초대 매치는 ELO 미반영.
- 리더보드는 이미 결정한 **자체 서버 하나**(웹·Android·Steam 공용)에 얹는다.

## 10. 서버 (개요만)

- 각 클라이언트가 자기 판을 시뮬레이션(개인 런 엔진 그대로, 멀티 규칙 셋만 `_buildRules`에 추가). 서버는 **이벤트 중계 + 상태 스냅샷**(WebSocket): 공격·폭탄·잔액·평판·일차·표정 상태.
- 폭탄 목적지 랜덤은 **서버가 정한다**(클라 조작 방지).
- 매치 종료 시 서버가 각 클라의 입력 로그로 **재실행 검증**(같은 시드이므로 결정적). 안 맞으면 그 판은 무효·ELO 미반영.
- 끊긴 사람은 30초 자동 대기 처리, 3분이면 폐업 판정.

## 12. 결정된 것 · 열린 것

결정(2026-09-26): 시간은 **눌러야 진행·타이머 없음**, 공격 트레잇은 **나 빼고 전원**, 입고 시드는 **매치 공유**.

남은 질문:

1. 마켓이 하루를 쓰는 게 맞나 — 다른 해석은 "마켓은 시간을 안 쓰지만 사이클마다 1회". 하루 소모가 더 직관적이라 문서안으로.
2. 먼저 마감한 사람이 관전만 하는 게 심심하지 않은지 — 관전 중 응원 이모지 정도.
3. 폭탄 소멸 조건(6칸/1일에 터짐)이 너무 늦지 않은지 — 4인이면 한 바퀴 반이다.
4. 멀티 전용 시작 창고·계약 3종의 실제 값 — 개인 런 봄 시작값에서 창고 +4칸으로 시작하는 게 후보.
5. 전원 공격이라 공격 트레잇 비율(40%)과 한 방 세기(반나절)가 맞는지는 봇 3명 로컬 판에서 먼저 본다.

## 13. 구현 순서 (제안)

| 단계 | 내용 |
|---|---|
| 1 | 멀티 규칙 셋(마켓 하루 소모·배차 무제한·즉시 결제·마켓 단순화·퍽 3택1) — **혼자서 봇 3명과** 돌아가게. 서버 없이 로컬 봇으로 연출 전부 |

1단계가 끝나면 서버 없이도 "멀티 감각"을 폰에서 볼 수 있다 — 연출 밀도가 맞는지 거기서 먼저 잡는다.

## 부록 A. 1단계 구현 — 봇 3명과 로컬 난투 (2026-09-26)

13장 1단계를 그대로: **서버 없이 혼자서 봇 3명과** 석 달을 돈다. 트레잇·폭탄·포트레잇 표정·연출(2단계)과 서버·ELO(3단계)는 아직 없다.

### 규칙이 문서와 다른 곳 (봇 판에서 잡은 값)

| 문서 | 구현 | 왜 |
|---|---|---|
| 물량 `× (1 + 0.025 × day)`, 마지막 보름 ×1.5 | **0.03 · ×1.8** | 봇 4명 판에서 문서값은 완주 100%·잔액 5천. 죽는 건 물량이어야 하는데 안 죽었다 |
| 평판 상한 +5 | **+8** | +5 면 석 달에 13번 올랐다(퍽 13장). 8이면 7~9번 |
| 배차비 유가 (값 없음) | 하루 **+1%** (78일 +78%) | 후반 잔액이 그냥 쌓이지 않게 |
| 퍽 3계열 각 5장 | **16장 중 1단계에서 작동하는 9장만 뽑힌다** (`phase`) | 방패·소나기 면역·공격 배율은 트레잇이 있어야 뜻이 있다 — 효과 없는 카드를 고르게 하지 않는다 |

시작 창고는 개인 런 봄 시작값 **+4칸**(열린 질문 4의 후보 그대로). 계약은 동네 택배의 셋(대량·냉장·파손) — "일반·대량·냉장"이라고 썼지만 일반 전용 계열은 없다.

### 입고 대본 공유는 어떻게

`_makeSchedule` 은 원래 본 난수 흐름(`this.rng`)에서 굴린다 — 파손·도난 굴림이 사람마다 다르니 같은 시드여도 사이클 2부터 대본이 갈린다.
멀티는 `_sharedSchedule`: **(시드, 사이클)에서 파생한 씨앗**으로 따로 굴리고(`_campaignRoll` 과 같은 수법), 사람마다 달라지는 입력(평판 배율·등급 배율·고객 신뢰 단계)을 쓰지 않는다(`fixedCustLevel: 2`).
🛃·대형·🧊 는 아예 오지 않는다(`noRepUnlock`) — 새 계약이 없으니 실을 곳이 없다.

### 시계가 다르다는 것

봇은 사람이 하루를 넘길 때마다 제 속도(1.15 · 1.0 · 0.85)로 따라온다(`MULTI.tick`). 빠른 봇은 사람보다 먼저 끝나고, 느린 봇은 결과 화면에서 끝까지 돌린다(`finishAll`) — 관전은 4단계.
봇의 장 보기도 하루를 쓴다(사이클에 한 번까지). 봇은 사람과 같은 시드라 **같은 전략이면 같은 판**이 나온다 — 사람이 봇과 똑같이 두면 잔액도 같다.

### 봇 밸런스 (test/multi-sim.js · 12매치 · 봇 4명)

완주 98% · 잔액 4,300c · 장 5회 · 평판 8단계 · 반송 5. 전략별 완주 greedy 100 · balanced 100 · saver 92%.
봇이 안 죽는다 — **사람 플레이테스트로 다시 잡는다**(열린 질문 5). 죽는 길은 하나뿐이다: 잔액이 마이너스면 못 부르고 → 물량이 쌓이고 → 평판 0.

### 남은 것 (2단계)

트레잇·이삿짐 폭탄·포트레잇 표정·피격/발사 연출·D-카운트 배너·순위 변동 금색 토스트(지금은 글자 토스트만). 상대 줄은 이름·순위·창고 막대·평판 점·잔액·일차까지만.

## 부록 B. 2단계 구현 — 트레잇 · 이삿짐 폭탄 · 포트레잇 · 연출 (2026-09-26)

13장 2단계. 서버는 아직 없다 — 라우팅(누구에게 가나)은 `multi.js` 가 매치 난수로 정한다(3단계에서 서버가 이 자리를 맡는다).

### 트레잇 (3장)

- `META.MULTI.TRAITS` 16장(공격 8 · 보너스 8, `weight` = 등장 비중). 이름·설명은 locales `meta.MULTI.TRAITS`.
- **대본에 박는다** — `_sharedSchedule` 이 스펙에 `trait` 를 붙이므로 넷이 같은 택배에 같은 트레잇을 받는다. 운은 "누가 기한 안에 내보내느냐"에만 있다. 비율은 일차에 비례해 15% → 35%(`traitRate`), 공격 40 : 보너스 60(`attackShare`).
- 발동은 `_fireTrait(p)` — 호출·직접 배송으로 **기한 안에** 나간 택배만. 반송·폐기·기한 초과는 불발. 💰 웃돈만 보상 계산 안에서(×2).
- 공격은 `outbox` 에 `{ type:'attackOut', trait, mult, focus }` 로 쌓이고 `MULTI.route()` 가 **나 빼고 전원**(마감·폐업 제외)의 `inbox` 에 넣는다. 🎯 한 방이 걸려 있으면 1위 한 명에게 ×3.
- 받는 쪽은 **다음 날로 넘길 때**(`_startTurn` → `_multiDay`) 적용한다(`_applyAttack`). 순서: 💨 잽(`dodgeProb`) → 🛡 방패(1겹 소모) → 🏠 지붕(소나기만) → 효과. 세기 `mult`(퍽 ⚔ ×1.5, 🎯 ×3)는 정수로 올려 곱한다(평판 −1 → −2, 봉인 −3 → −5칸).
- 임시 칸(📦 +3 · 🔒 −3)은 `capMods` 로 `warehouse.cap` 을 직접 바꾸고 3일 뒤 되돌린다. 🚧 는 `roadblockDay`(`offFor` 가 본다), 🧊 는 `freshFreezeUntil`, 🚚 는 `freeTruckNext`(`callFee` 가 한 대 뺀다), 🎯 는 `focusNext`.
- 퍽 2단계 카드가 이제 뽑힌다: 🛡 상시 방패(`shieldPassive`, 매일 1겹 보충) · 🏠 지붕(`rainImmune`) · 💨 잽(`dodgeProb 0.5`) · 🎲 장전(`attackEcho 0.25` — "등장 +10%p" 는 대본이 공유라 개인 퍽으로 못 바꾼다, 두 번 나가는 확률로 바꿨다) · 🧨 무거운 이삿짐(`bombGrow`) · ⚔ 날 세우기(`attackMult`).

### 이삿짐 폭탄 (4장)

- 보관 계약의 자리를 그대로 쓴다: `storage[]` 에 `kind:'bomb'` — `usedVolume` 이 세고, 3D 에 보관짐 상자로 놓이고, 하루 +2c(`_tickStorage`). `returnStorage` 는 거부(`err.bombStuck`).
- 카운트 0 → `outbox` 에 `bombMove { size+1, days−1 }`(상한 6칸·하한 1일). `route()` 가 랜덤 상대(🔄 되돌리기면 보낸 사람)에게 `receiveBomb`. 갈 곳이 없으면(전원 마감) 소멸. 매치당 동시 `BOMB.max` 4.
- **6칸/1일짜리가 도착하면 터진다**: 창고 초과분만큼 택배 도난(야외부터) + 평판 −(최대 3), 그 뒤 소멸.
- 발생원: 🧨 트레잇 출고 + **사람이 사이클을 넘길 때** 하나 자동 투하(`cycleDrop`, 랜덤 한 명 — 나도 포함).

### 포트레잇 · 연출 (7·8장)

- 상대 줄 카드에 얼굴: 스토리 스프라이트를 빌린다(`MULTI.FACES` = park·yeo·noh·kang·han·ahn, `Story.sprite`). 표정은 기본 / 창고 80%↑ 진땀(`worry`) / 맞은 뒤 4초 놀람(`shock`) / 1위 웃음 / 폐업 = 그레이아웃 + 「폐업」 / 마감 = 세피아 + 「마감」. **전용 표정(진땀·망연자실) 그림은 아직 없다** — 박 반장·한 사장 외엔 `neutral` 로 떨어진다.
- 카드 한 줄에 🧨(들고 있는 폭탄 수)·🛡. 내 카드 아래 `#multi-status` 한 줄: 방패 겹수 · 임시 칸 · 🚧 · 🧊 · 🚚 · 🎯 · 들고 있는 이삿짐.
- 발사: 아이콘이 내 창고(화면 가운데)에서 상대 포트레잇으로 날아가 **흔든다**(`flyIcon`, `.mp.hit`). 봇끼리의 공격·이사도 포트레잇 사이를 난다(`match.news`).
- 피격: 빨간 비네트 0.35초(`body.mhit`) + 흔들림 + 한 줄 토스트 "○○ → 🐭 쥐: 신선 1개 폐기". 방패가 막으면 포트레잇 앞에서 🛡 가 깨진다(`.shieldbreak`).
- 폭탄 도착: 쿵(`scene.shake`) + 토스트. 폭발: 흔들림 + 망연자실(`scene.mope`).
- 배너(`#mbanner`): 「○○ 폐업」(빨강) · 「○○ 마감 · 잔액 N c」(세피아) · D-30 · D-7 · 마지막 날 · 「마감 폭주 — 마지막 보름」.
- 연속 만차: 난투에서는 켠다(`shows('chain')`) — 기존 체인 연출(×1.08/단계, 최대 4)이 그대로 돈다. **5연속부터 라벨 커지는 배수(×1.2→×2)** 는 아직 기존 수치 그대로. 마지막 날 BGM 템포 업도 미구현.
- 택배 칩 왼쪽 위에 트레잇 뱃지(`.tb.attack` 붉은 테두리 / `.tb.bonus` 금 테두리). 택배 상세에 한 줄.

### 봇

봇은 트레잇을 신경 쓰지 않는다(맞으면 맞는다). 퍽 선호에 방어 카드(🛡·💨)를 넣었다. 12매치: 완주 92%(saver 75%) · 잔액 5,100 — 1단계보다 조금 더 죽는다.

### 남은 것 (3단계 전에)

포트레잇 전용 표정 그림 · 5연속 만차 배수 라벨 · 마지막 날 BGM 템포 · 열린 질문 5(공격 비율·한 방 세기)는 사람 플레이로.

# 상하차의 신 — 메타 진행 기획서 v0.1

## 회사 · 퍽 · 시나리오 · 도전과제

이 문서는 `GAME_DESIGN.md`(런 내부 규칙 v0.2) 위에 얹는 **런 바깥의 진행 구조**를 정의한다. 런 내부 규칙은 바꾸지 않는다.

### 용어 정리

기존 기획서의 "운송 업체"는 런 안에서 호출하는 외부 물류 회사다. 이 문서에서 플레이어가 고르는 것은 **"회사"**(플레이어 자신의 택배 회사)로 부른다. 혼동을 피하기 위해 문서 전체에서 다음처럼 구분한다.

| 용어 | 의미 |
|---|---|
| 회사 | 플레이어가 런 시작 시 고르는 자기 택배 회사. 시작 창고·시작 계약·고유 특성을 가진다 |
| 운송 업체 | 런 안에서 계약하고 호출하는 외부 회사 (기존 기획서와 동일) |
| 퍽 | 런 시작 시 장착하는 소규모 규칙 변경. 회사와 별개로 해금·선택 |
| 시나리오 | 런의 길이·입고 패턴·특수 규칙·승리 조건을 정하는 모드 |
| 도전과제 | 회사·퍽·시나리오를 해금하는 조건. 런 중 또는 누적으로 달성 |
| 프로필 | 기기에 저장되는 메타 진행 상태 (해금 목록, 누적 통계, 도전과제 달성 여부) |

## 1. 목표와 원칙

기존 프로토타입은 매 런 퍽 5종 중 2개를 고르는 구조였다. 이를 다음처럼 바꾼다.

1. **회사가 런의 정체성을 정한다.** 회사마다 시작 창고, 시작 계약, 고유 패시브와 고유 약점이 있어 같은 시나리오도 다른 문제로 느껴져야 한다.
2. **해금은 실력의 증명이다.** 회사·퍽·시나리오는 돈이나 경험치가 아니라 **도전과제**로 연다. 반복 플레이 자체가 아니라 특정 플레이를 해낸 것이 보상이다.
3. **퍽은 양념이다.** 퍽 하나의 힘은 기존 기획서 기준(월 40~80 크레딧 상당 또는 페널티 1~2)을 넘지 않는다. 회사 패시브는 그보다 크지만 약점과 짝을 이룬다.
4. **시나리오가 난이도와 길이를 정한다.** 3개월 표준 외에 짧은 모드, 긴 모드, 규칙이 뒤틀린 모드가 있다.
5. **한 런은 "시나리오 → 회사 → 퍽" 순서로 준비한다.** 시나리오가 문제를 내고, 회사가 도구를 정하고, 퍽이 미세 조정한다.

### 회사 vs 퍽의 역할 분담

| 항목 | 회사 | 퍽 |
|---|---|---|
| 개수 | 런당 1개 | 런당 1~3개 (슬롯 해금에 따라) |
| 영향 범위 | 시작 창고·시작 계약·마켓 등장 확률·핵심 규칙 | 수치 미세 조정, 특정 상황 대응 |
| 힘의 크기 | 큼 (약점 동반) | 작음 (약점 없음) |
| 해금 | 회사별 도전과제 1개 | 퍽별 도전과제 또는 누적 기록 |

## 2. 런 준비 흐름

```
타이틀 → [시나리오 선택] → [회사 선택] → [퍽 장착] → 런 시작
```

1. **시나리오 선택**: 해금된 시나리오 목록. 각 시나리오는 길이, 규칙 변경, 승리 조건, 추천 회사가 표시된다. 잠긴 시나리오는 해금 조건이 보인다.
2. **회사 선택**: 해금된 회사 목록. 시작 창고·계약·패시브·약점, 그리고 이 시나리오에서의 개인 최고 기록이 보인다. 잠긴 회사는 실루엣과 해금 조건만 보인다.
3. **퍽 장착**: 해금된 퍽 중 슬롯 수만큼 선택. 회사와 상충하는 퍽은 회색 처리되고 이유가 표시된다 (예: 냉장 구역이 0인 회사에 냉장 퍽).
4. **런 시작**: 시드 표시. 데일리 시나리오는 시드 고정.

퍽 슬롯은 기본 1개, 도전과제로 2개·3개까지 늘어난다 (7장).

## 3. 회사

총 9개. 기본 1개는 처음부터 열려 있고, 나머지 8개는 도전과제로 연다. 해금 순서는 강제하지 않지만, 도전과제 난이도가 자연스러운 순서를 만든다.

### 공통 규칙

- 시작 자금·창고·계약은 회사가 정한다. 시나리오가 이를 다시 보정할 수 있다 (예: 자금난 시나리오는 시작 자금 -50%).
- 고유 패시브는 런 내내 적용되고 끌 수 없다.
- 고유 약점도 마찬가지다. 약점은 퍽으로 상쇄할 수 있지만 완전히 없앨 수는 없게 수치를 잡는다.
- 마켓 등장 가중치: 회사마다 특정 운송 업체가 마켓에 더 자주 나온다. 확률표는 기존 기획서 13장에 곱하는 배율로 표현한다.

### 3.1 동네 택배 (기본)

| 항목 | 내용 |
|---|---|
| 콘셉트 | 균형형. 튜토리얼과 기준선 |
| 시작 창고 | 용량 24 / 냉장 6 / 초대형 1 (= 기존 균형형 창고) |
| 시작 자금 | 600 |
| 시작 계약 | 일반 라인 4회, 타겟 멀티모달 3회, 냉장 물류 2회, 대량 분류 1회 (기존과 동일) |
| 고유 패시브 | **동네 단골**: 매월 첫 호출의 처리량 +1 |
| 고유 약점 | 없음 |
| 마켓 가중치 | 없음 |
| 해금 | 처음부터 |

기준점이다. 다른 회사의 힘은 이 회사 대비로 잰다.

### 3.2 프레시 로지스틱스

| 항목 | 내용 |
|---|---|
| 콘셉트 | 신선식품 특화 |
| 시작 창고 | 용량 22 / 냉장 10 / 초대형 1 |
| 시작 자금 | 450 |
| 시작 계약 | 냉장 물류(신뢰) 3회, 일반 라인 4회, 타겟 멀티모달 2회, 대량 분류 1회 |
| 고유 패시브 | **콜드체인**: 신선식품 부패 카운트 +1턴. 냉장 물류 호출 시 신뢰도 경험치 +1 추가 |
| 고유 약점 | **냉장 편중**: 파손주의·국제운송 보상 -10%. 대형화물 업체는 마켓에 등장하지 않음 |
| 마켓 가중치 | 냉장 물류 ×2.0, 냉장고 증설 ×2.0 |
| 해금 | 도전과제 「신선 배송왕」: 한 런에서 신선식품 15개를 부패 없이 처리 |

신선식품 비율이 높은 시나리오(폭염)에서 빛나고, 국제·파손이 많은 시나리오에서 고전한다.

### 3.3 강철 창고

| 항목 | 내용 |
|---|---|
| 콘셉트 | 대형화물·공간 특화. 산업형 창고 |
| 시작 창고 | 용량 34 / 냉장 0 / 초대형 3 |
| 시작 자금 | 350 |
| 시작 계약 | 대형 화물 2회, 대량 분류 2회, 일반 라인 4회, 타겟 멀티모달 2회 |
| 고유 패시브 | **적재 전문**: 대형(4)·초대형(7) 택배의 창고 점유량 -1. 대형 화물 업체 회당 처리량 +1 |
| 고유 약점 | **냉장 없음**: 신선식품은 항상 상온 보관(부패 2배 속도). 냉장고 증설을 사도 냉장 용량은 최대 4 |
| 마켓 가중치 | 대형 화물 ×2.0, 창고 확장 ×1.5, 냉장 물류 ×0.5 |
| 해금 | 도전과제 「거인의 어깨」: 한 런에서 초대형(7) 택배 5개를 기한 내 처리 |

신선식품이 들어오면 즉시 타겟으로 빼거나 포기해야 한다. 대형 입고가 많은 시나리오(항만)에서 최강.

| 고유 약점 | **협소**: 창고 확장 업그레이드 효과 절반(+4/+5/+6). 초대형 택배는 항상 임시 공간 +3 |

기존 기획서가 "불리하다"고 정의한 매 턴 호출 플레이를 정식 스타일로 만드는 회사다. 창고 초과 페널티와 싸운다.

## 4. 퍽

퍽은 4개 계열, 총 24개. 계열마다 해금 방식이 다르다. 한 계열의 퍽은 서로 겹쳐 장착할 수 없다 (같은 계열 1개까지) — 슬롯이 3개여도 세 계열이 섞이게 된다.

### 4.1 계약 계열 (호출과 계약을 다룬다)

| 퍽 | 효과 | 해금 |
|---|---|---|
| 장기 거래 | 모든 계약 비용 -10% | 기본 |
| 선불 할인 | 매월 첫 계약 구매 -40 | 누적 계약 구매 10회 |
| 재계약 보호 | 계약 교체 시 잔여 호출 1회 보존 | 잔여 호출 3회 이상인 계약을 교체하고 런 클리어 |
| 단골 업체 | 같은 운송 업체 계약을 다시 사면 신뢰도 경험치 5를 가지고 시작 | 한 계약을 신뢰 3단계까지 올림 |
| 예비 기사 | 매월 1회, 잔여 호출이 0인 계약을 한 번 더 호출 가능 | 잔여 호출 0인 계약 4개로 월말을 맞고 생존 |
| 묶음 할인 | 한 호출로 4개 이상 처리하면 그 계약의 잔여 호출 소모 없음 (월 1회) | 한 호출로 6개 이상 처리 |

### 4.2 창고 계열 (공간과 보관을 다룬다)

| 퍽 | 효과 | 해금 |
|---|---|---|
| 공간 최적화 | 모든 택배 크기 -1 (최소 1) | 기본 |
| 냉장 전문가 | 신선식품 유통기한 +1턴 | 신선식품 부패 0회로 런 클리어 |
| 임시 적재장 | 창고 초과 1~2는 페널티 없음 | 창고 초과 상태로 5턴 이상 버티고 런 클리어 |
| 선반 증설 | 시작 용량 +4 | 창고 확장을 한 런에 2개 구매 |
| 냉동고 | 냉장 구역 안의 신선식품은 첫 2턴 동안 부패 카운트 정지 | 냉장고 증설 2회 구매한 런 클리어 |
| 야적장 | 초대형 보관 가능 수 +1, 초대형 임시 공간 페널티 3→2 | 초대형 3개를 동시에 보관 |

### 4.3 운영 계열 (턴 진행과 페널티를 다룬다)

| 퍽 | 효과 | 해금 |
|---|---|---|
| 스킵 보너스 | 대기 후 다음 호출의 처리량 +1 | 기본 |
| 폐기 보험 | 런당 첫 폐기 택배의 페널티 무효 | 기본 |
| 심호흡 | 월초에 스트레스 -1 | 스트레스 15 이상에서 런 클리어 |
| 연장 근무 | 기한 초과 택배의 보상 감소 25%→10% | 기한 초과 택배 10개를 처리하고 클리어 |
| 예지 | 입고 예정을 다음 2턴 → 4턴까지 표시 | 대기 40회 누적 |
| 비상 대응 | 긴급 특송 계약 비용 -30%, 마켓에 긴급 특송이 매월 1회 이상 등장 | 긴급 특송으로 부패 직전 신선식품 처리 |

### 4.4 수익 계열 (돈을 다룬다)

| 퍽 | 효과 | 해금 |
|---|---|---|
| 정기 고객 | 일반 택배 보상 +5 | 일반 택배 누적 100개 |
| 프리미엄 서비스 | 특수 운송 보너스 +5 (신선·파손·국제·대형 모두) | 특수 택배 4종을 한 런에서 모두 전문 업체로 처리 |
| 월말 결산 | 월말 창고 사용률이 60% 이하이면 +60 크레딧 | 월말 사용률 40% 이하로 월 마감 3회 |
| 물류 컨설팅 | 신뢰도 경험치 획득 +1 (모든 조건) | 신뢰 2단계 계약 3개 보유 |
| 절세 | 월말 운영비 -20 | 자금 1,500 이상으로 런 클리어 |
| 투자 유치 | 시작 자금 +150, 대신 월말 운영비 +20 | 자금 100 이하로 월말을 넘기고 클리어 |

### 퍽 밸런스 규칙

- 한 퍽의 가치는 월 40~80 크레딧 또는 페널티 1~2 상당. 표의 수치는 이 범위에 맞춘 초기값이며 플레이테스트로 조정한다.
- 회사 약점을 정면으로 지우는 조합은 막는다. 예: 강철 창고 + 냉장 전문가는 허용(상온이라도 1턴 벌 뿐), 강철 창고 + 냉동고는 불가(냉장 구역이 없음). 불가 조합은 UI에서 회색 처리.
- 같은 계열 퍽은 하나만. 계약 계열 둘을 겹치면 호출 경제가 무너지기 때문이다.

## 6. 도전과제

도전과제는 세 종류다. **런 내**(한 런 안에서 달성), **누적**(여러 런에 걸쳐 합산), **메타**(해금 상태 자체). 달성은 런 중 즉시 판정하고, 런이 게임오버로 끝나도 이미 달성한 것은 유지한다. 단 "클리어" 조건이 붙은 것은 승리해야 인정된다.

### 6.1 회사 해금

| 도전과제 | 종류 | 조건 | 해금 |
|---|---|---|---|
| 신선 배송왕 | 런 내 | 신선식품 15개를 부패 없이 처리 | 프레시 로지스틱스 |

## 7. 프로필과 저장

프로필은 런 저장과 별개 키에 둔다. 런 저장은 기존처럼 하나뿐이고, 프로필은 런을 넘어 유지된다.

```
profile = {
  version: 1,
  unlocked: { companies: [...], perks: [...], scenarios: [...], perkSlots: 1 },
  achievements: { [id]: { done: true, at: timestamp } },
  stats: {                       // 누적
    runs, clears, deliveredByType: {normal, fresh, fragile, intl, large},
    waits, calls, contractsBought, discarded, bestScore,
    clearsByCompany: {}, clearsByScenario: {}, dailyStreak, lastDaily
  },
  records: { [scenario]: { [company]: { bestScore, bestMonth } } },
  recentRuns: [ ...최근 20개 ]
}
```

- 기존 프로토타입의 저장/기록은 마이그레이션한다. 기존 런 기록은 "표준 3개월 · 동네 택배"로 분류한다.
- 도전과제 달성은 런 중 **즉시** 프로필에 쓴다(앱이 죽어도 유지).
- 해금 알림은 런 중에는 토스트로만 띄우고, 런 종료 화면에서 다시 모아 보여준다.

## 8. 첫 사이클 (플레이어 동선)

플레이어가 겪게 될 순서를 설계 의도대로 적으면 다음과 같다.

1. 표준 3개월을 동네 택배로 플레이. 첫 클리어 → 퍽 슬롯 2번, 반기 결산 해금.
2. 그 과정에서 신선식품을 잘 다루면 「신선 배송왕」(프레시), 계속 호출했으면 「무정차」(도심 퀵) 중 하나가 먼저 열린다. 플레이 스타일이 해금을 정한다.
3. 회사 3개가 열리면 데일리가 열리고, 성수기·폭염·자금난 같은 변형 시나리오가 누적 조건으로 하나씩 열린다.
4. 반기 결산 클리어 → 국영 우편, 무한 운영. 회사 5개 → 퍽 슬롯 3번.
5. 최종 목표는 전 회사·전 시나리오 클리어와 무한 운영 점수.

목표 시간: 첫 회사 해금까지 3~5런, 회사 5개까지 15~20런, 전부 해금까지 40런 전후.

## 9. 밸런스 가드레일

- **회사 패시브 총량**: 강점의 가치 ≈ 월 100~150 크레딧 상당, 약점 ≈ 월 50~100 상당. 순이익이 동네 택배 대비 +50 이내가 되게 잡는다. 회사 간 승률 차이는 표준 3개월 기준 ±10%p 안.
- **퍽**은 기존 기획서 상한(월 40~80) 유지. 회사 약점을 완전히 지우는 퍽 조합은 금지 목록으로 관리.
- **시나리오 승률 목표** (균형형 봇 기준): 표준 85%, 반기 50%, 성수기 60%, 폭염 55%, 파업 65%, 항만 55%, 자금난 50%, 데일리 60~80%(변형에 따라).
- 시뮬레이터(`test/sim.js`)에 회사·퍽·시나리오 매개변수를 넣어 위 승률표를 자동 산출하고, 표에서 ±15%p 벗어나면 조정 대상으로 표시한다.

## 11. v0.2 변경 (플레이테스트 반영)

플레이테스트 피드백으로 런 내부 규칙 세 가지를 바꿨다. 기획서 v0.2(`GAME_DESIGN.md`)의 해당 항목을 대체한다.

### 11.1 일반 라인 → 자체 배송

일반 라인은 타겟 멀티모달보다 처리량이 적어 하위호환이었다. 계약에서 빼고 **상설 행동**으로 만든다.

| 항목 | 내용 |
|---|---|
| 위치 | 계약 슬롯 밖, 대기 버튼 옆 |
| 대상 | 오래된 순 일반 택배, 부피 **2칸**까지 (크기 1은 2개, 크기 2는 1개) |
| 비용 | 없음. 호출 횟수 없음. 마켓과 무관 |
| 턴 | 소모한다 (대기·호출과 같은 급의 행동) |
| 보상 | 70% (직접 배송은 마진이 낮다) |
| 신뢰도 | 쌓이지 않음 |

의도: 일반 택배 처리에 "싸지만 느리고 남는 게 적은" 기본값을 주고, 대량 분류 계약은 "한 번에 4개, 정가"로 차별화한다. 도심 퀵·국영 우편은 자체 배송 +1칸.

### 11.2 긴급 특송 → 턴을 쓰지 않는 즉시 행동

타겟 멀티모달과 구분되지 않던 긴급 특송을 **턴 미소모** 행동으로 바꾼다. 호출하면 즉시 1개(신뢰 3단계: 2개)가 처리되고, 같은 턴에 다른 호출·대기를 이어서 할 수 있다. 보너스 없음, 300c 2회. 대기 전략의 안전장치라는 원래 역할이 그대로 규칙이 된 것이다.

### 11.3 신뢰도 → 업체 귀속, 문턱 3 / 8 / 15

신뢰도가 계약에 붙어 있어 계약 교체 시 사라지고, 문턱(5/12/20)이 호출 횟수 대비 너무 멀었다. 이제 신뢰도는 **런 안에서 업체(냉장 물류, 대량 분류 …)에 누적**되고 계약을 교체해도 유지된다.

| 단계 | 필요 xp | 효과 |
|---|---:|---|
| 1 | 3 | 회당 처리량 +1 |
| 2 | 8 | 4번째 호출마다 +1개 |
| 3 | 15 | 전용 능력 |

획득: 호출 1회당 정상 처리 +1, 처리량 80% 이상 +1, 전문 업체로 특수 택배 +1. 가득 채워 부르면 매번 +2~3이라 5~6회 호출로 3단계.
UI 가이드: 계약 버튼에 3칸 게이지와 `현재/다음` xp, 호출 화면에 "이 호출 +Nxp (내역)"과 다음 단계 효과를 보여준다.
퍽 「단골 업체」는 "모든 업체 신뢰도 3xp로 시작"으로 바뀐다.

### 11.4 화면

- 택배 목록은 **급한 순** 정렬 (부패 직전·기한 초과 → 남은 턴 오름차순). 각 줄 앞에 긴급도 점(빨강 ≤1턴, 주황 2, 노랑 3).
- 대기 버튼에 **다음 턴 예상**: 창고 사용량, 기한 초과·부패 예정 수. 초과면 빨간 버튼.
- 텍스트 축약: 계약 버튼은 짧은 이름·잔여·회당·대상·신뢰 게이지만, 택배 줄은 `종류 N칸 · 보상 · ⏳턴`.

## 12. v0.3 변경 — 해금 체인과 악랄한 시나리오

### 12.1 회사 해금을 단계로
기존에는 모든 회사가 "특별히 노력해야" 열렸다. 표준 시나리오는 그대로 두고, 대신 회사 해금을 세 단계 체인으로 바꿨다.

| 단계 | 회사 | 조건 | 성격 |
|---|---|---|---|
| 시작 | 동네 택배 | — | 기준선 |
| 1단계 | 도심 퀵 | 런 3회 플레이 (승패 무관) | 그냥 하다 보면 |
| 1단계 | 국영 우편 | 첫 클리어 (반기 결산·퍽 슬롯 2와 함께) | 그냥 하다 보면 |
| 1단계 | 짠돌이 운송 | 클리어 2회 | 그냥 하다 보면 |
| 2단계 | 프레시 로지스틱스 | 신선식품 누적 30개 | 그 종류를 자주 다루면 |
| 2단계 | 유리방 물류 | 파손주의 누적 30개 | 〃 |
| 2단계 | 글로벌 익스프레스 | 국제운송 누적 30개 | 〃 |
| 2단계 | 강철 창고 | 크기 4 이상 택배 누적 20개 기한 내 처리 | 〃 |
| 3단계 | 스타트업 딜리버리 | 서로 다른 회사 3개로 클리어 | 도전 |

옛 조건(신선 배송왕·거인의 어깨·무정차·깨지지 않는·기다림의 미학)은 기록용 도전과제로 남긴다. 누적형 도전과제는 도감·회사 선택 화면에서 `(현재/목표)` 진행도를 보여준다.

### 12.2 시나리오를 더 악랄하게
표준 3개월은 손대지 않고, 나머지를 조인다.

- 성수기: 입고 ×1.8, 폭주 4회, 처리 목표 38개.
- 폭염: 신선 +20%p, 폭염 경보 월 3회, 입고 +10%.
- 파업: 입고 +20%, 운영비 +30.
- 항만: 초대형 7%, 입고 +10%.
- 자금난: 운영비 240, 마켓 가격 +10%, 목표 자금 600.
- **블랙 프라이데이 (신규)**: 1개월, 입고 ×2.3, 폭주 4회, 가격 ×1.4, 보상 +15, 시작 호출 +3. 24개 처리해야 승리. 해금: 성수기 클리어.
- **감사 (신규)**: 모든 기한 -1턴, 기한 초과 보상 -50%, 월초 스트레스 +1, 운영비 +30. 기한 초과 처리 4개 이하로 3개월 생존. 해금: 완벽한 달(페널티 0으로 한 달 마감).
